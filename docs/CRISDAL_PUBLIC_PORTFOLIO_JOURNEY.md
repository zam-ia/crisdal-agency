# Portafolio público · recorrido y campañas
- Para WhatsApp, DM o email, usar el enlace limpio: https://crisdal-agency.vercel.app/portafolio. No requiere acortador ni una web aparte. Desde un trabajo se puede volver a la colección, compartir el enlace o consultar la fecha. Usar el enlace de un caso cuando la consulta ya especifica el tipo de cobertura.
- Una campaña general de eventos debería abrir la home; un anuncio que promete mostrar trabajos reales puede llevar al portafolio una vez haya material autorizado. Un anuncio muy específico necesita una entrada coherente con su oferta y creatividad; no enviar toda la pauta a la misma página por defecto.
- Mantener los enlaces de campañas separados de los enlaces que el equipo copia por chat. Ejemplos a adaptar: `/?utm_source=meta&utm_medium=paid_social&utm_campaign=eventos_huancayo` y `/portafolio?utm_source=tiktok&utm_medium=paid_social&utm_campaign=muestras_eventos`. No constituyen configuración de TikTok Pixel ni validación del administrador de anuncios.
- Antes de pauta: cargar casos reales autorizados (ideal: una boda, un quinceaños y un evento corporativo), revisar enlace y consentimiento de cada medio, probar la entrada desde Meta/TikTok en móvil y distinguir clic a WhatsApp de consultas realmente recibidas. Confirmar atribución y consentimiento con los píxeles de cada plataforma antes de usar conversiones para optimizar.
- Esta rama no toca base de datos, políticas, campañas ni activación del portafolio social. Solo ajusta la experiencia pública y limita los datos enviados al componente del listado. Los videos siguen usando el reproductor existente bajo interacción.
